# gnss-fe — смеситель и фильтры к LibreSDR для пары L1/L5

Узлы между многочастотной ГНСС-антенной и LibreSDR (AD9363, режим 2R2T): смеситель, который переносит одну полосу ГНСС на частоту другой, и универсальная плата фильтра ПАВ с разъёмами SMA. Сплиттер и Bias-T — готовые модули (решение 2026-10-22; до того репозиторий задумывался под плату фронтенда целиком). Гетеродин смесителя даёт TX1 того же AD9363, поэтому оба канала когерентны: одна опора, один АЦП, постоянная межканальная задержка. Третий выход сплиттера — HackRF. Смеситель: основной кандидат — модуль HMC213 с AliExpress (пассивный, нужен усилитель гетеродина и МШУ-модуль перед ним), запасной — LTC5510 на своей плате по схеме демоплаты (демоплаты слишком дороги, 2026-10-22).

Узлы — часть исследовательского макета станции ионосферного мониторинга (`~/GitHub/kushpet/iono-gnss`): системные решения, частотный план и конфигурация gnss-sdr — там, в `docs/frontend.md`. Здесь — смеситель и фильтры: требования, компоненты, расчёты, KiCad, измерения.

Схема B (предложение 2026-10-22; в схеме A RX1 принимает L5, а ПАВ у смесителя меняются местами):

```
АНТЕННА ─ кабель ─ Bias-T 5 В ─ сплиттер 1→3 ─┬─► [плата ПАВ — по замерам] ──────────────► LibreSDR RX1: L1/E1/B1C
(МШУ 38 ± 2 дБ)     (готовый)   (готовый)      ├─► плата ПАВ L5 ─► смеситель ─► плата ПАВ L1 ─► LibreSDR RX2: L5/E5a/B2a
                                               │                     ▲ LO                      на 1575.42, спектр инвертирован
                                               │                     └── LibreSDR TX1, 2751.87 МГц (через усилитель для HMC213)
                                               └─► [плата ПАВ — по замерам] ──────────────► HackRF
```
