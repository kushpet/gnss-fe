# gnss-fe — аналоговый фронтенд L1/L5 для LibreSDR

Плата между многочастотной ГНСС-антенной и LibreSDR (AD9363, режим 2R2T). Один вход с питанием МШУ антенны, три выхода, вход гетеродина, вход питания. RX1 LibreSDR получает L5/E5a/B2a напрямую, RX2 — L1/E1/B1C, перенесённый смесителем на ту же частоту 1176.45 МГц. Гетеродин смесителя даёт TX1 того же AD9363, поэтому оба канала когерентны: одна опора, один АЦП, постоянная межканальная задержка. Третий выход — для HackRF как синхронного третьего канала.

Плата — часть исследовательского макета станции ионосферного мониторинга (`~/GitHub/kushpet/iono-gnss`): системные решения, частотный план и конфигурация gnss-sdr — там, в `docs/frontend.md`. Здесь — сама плата: требования, компоненты, расчёты, KiCad, измерения.

```
АНТЕННА ─ кабель ─► ANT ─ защита ─ Bias-T 5 В ─ делитель на 3 тракта
(МШУ 28–42 дБ)                                   │
        ┌────────────────────────────────────────┼──────────────────────────────────────┐
   ПАВ L5 ─ МШУ ─ П-звено ─ ФНЧ ─► OUT1    ПАВ L1 ─ МШУ ─ RF ┐                 ПАВ L2 (место) ─ МШУ ─ П-звено ─► OUT3
   → RX1: L5/E5a/B2a                                     смеситель ─ IF ─ ПАВ L5 ─ П-звено ─► OUT2   → HackRF (синхронный,
                                         LO ─ ФНЧ ─ П-звено ─ LO ┘                    → RX2: L1/E1/B1C,       после F2/F3)
                                         ▲ TX1 LibreSDR 2751.87 МГц                    спектр инвертирован
PWR 5 В → антенна 5 В с ограничением тока; МШУ 3.3 В; смеситель 5 В
```
